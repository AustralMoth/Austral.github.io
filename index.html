📘 Gestión de Excepciones en Python

Fundamento:
La gestión de excepciones permite que un programa no se rompa cuando ocurre un error. En lugar de eso, el programa puede manejar el problema y seguir funcionando.

¿Por qué es importante?
- Evita que el programa se cierre inesperadamente
- Mejora la experiencia del usuario
- Permite detectar errores comunes

Ejemplo básico:

try: edad = int(input("Edad: ")) except ValueError: print("Error: Ingresa un número válido")

Explicación:

  • try: intenta ejecutar el código
  • except: captura el error si ocurre
  • ValueError: ocurre cuando ingresas texto en vez de número

Errores comunes:

  • ValueError
  • FileNotFoundError
  • ZeroDivisionError

Objetivo:
Crear programas más seguros y profesionales.
